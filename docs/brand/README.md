# Amplifier logo

Three ascending capsule bars represent rising audio gain. The palette is pure black (`#000000`) and white (`#FFFFFF`), with no lettering, gradients, or shadows.

`logo.svg` is the scalable master mark. Android’s launcher foreground uses the same geometry in a 108 × 108 viewport, centered inside the adaptive icon safe area on a black background. Its monochrome layer supports Android’s themed icons. The notification icon uses the same silhouette enlarged to fill a 24 × 24 viewport. The app header and light/dark interface also use black and white.

`logo-concept.png` preserves the original generated design reference. The vector master removes raster texture and scales cleanly at launcher sizes.
